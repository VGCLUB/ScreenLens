视译 ScreenLens 2.0.2
===================

先退出旧版，再运行本文件夹中的 ScreenLens.exe。
保留整个文件夹，不要单独移动 exe；无需安装 Python、FFmpeg 或显卡环境。
旧 API 配置保留，显示配置自动升级为固定字号、单行分段、半透明底框。

屏幕实时翻译
1. 在“设置”填写自己的翻译 API Key，测试并保存。
2. 勾选“显示翻译字幕”，按 Alt+Q，紧贴原字幕框选。
3. 译文固定字号、始终一行，后方原字幕不擦除，只添加半透明底框。
4. 可最小化控制窗口；字幕层鼠标穿透，不抢焦点。

Alt+Q 框选；Alt+W 暂停/继续；Alt+S 重译；Alt+T 显示/隐藏译文。
新版本首次使用请重新框选一次。默认固定字号 26 px、底框不透明度 55%。
字号只跟随设置，不跟随原字幕变化；可调整字体、固定字号、底框不透明度与位置偏移。
底框宽度和高度固定，只占一条字幕的空间；框选过矮时会扩展显示层，识别区域不变。
长译文按单行分段切换，不缩小字号、不改成多行；译文自带换行也会合并。
每段按长度保留阅读时间，最后一段停留等待下一句，不循环滚动。
新字幕翻译完成后优先切换，完整译文保留在主窗口，避免分段堆积导致延迟。
设置里仍可手动选择旧版局部文字修复或透明文字显示方式。
窗口流式显示译文，覆盖字幕在整句完成后一次更新，等待下一句时保留上句。
激活 Windows 水印自动过滤；其他台标、游戏提示可在“额外忽略文字”中每行添加一条。
默认锁定主字幕位置，位置明显变化时重新框选；需要多个文字块时可关闭“锁定主字幕”。
默认容忍 800 ms 的短暂漏识别，避免字幕闪退。
最短阅读时间从整句翻译完成时计算，默认 1200 ms；分页时给每段留出阅读时间。
原文已消失、下一句还没出现时，允许已请求的译文完成并保留阅读时间。
希望严格跟随原文消失，可把最短阅读时间设 0，减小漏识别容忍时间。
实时翻译有 OCR 和网络延迟，无法让尚未翻译完成的文字零延迟出现。

MP4 视频自动译制
1. 点击“导入 MP4 · 字幕识别 / 语音识别与译制”。
2. 导入视频，选择目标语言和输出文件。
3. 自动模式依次尝试：内嵌字幕轨道、画面硬字幕 OCR、无字幕时本地语音识别。
4. 点击“开始译制”，等待完成后打开输出目录。

默认扫描画面下方字幕；字幕在其他位置，可在预览中拖动框选。
预览下方滑块可查看其他时间，恢复自动区域可清除手动框选。
已知没有字幕时，选择“只用语音识别”可跳过整片 OCR 扫描。
base 多语言语音模型已内置；small 更准确但首次需联网下载。
默认采样 5 帧/秒，间隔约 0.2 秒；短字幕可选 10，速度优先可选 2。

输出 xxx.mp4、xxx.srt、xxx.original.srt、xxx.project.json。
成片包含译文画面与原声；SRT 可编辑；项目包含本地输入路径、字幕和样式，不含密钥。
视频采用 H.264、原声重新编码 AAC，按输入标称帧率输出；可变帧率会转为固定帧率。
不覆盖原视频，输出重名自动编号。取消后已完成的字幕和项目文件可能保留。
内嵌字幕会尽量复用可导出的基础字体、字号、颜色信息。
语音生成字幕没有原样式参考，默认透明白字黑描边。

效果边界
硬字幕已经与画面合并，无法精确恢复原字体或保证背景完全无痕。
局部文字修复主要修改笔画与描边附近，复杂纹理可能留有修补痕迹。
花字、动画、竖排、过小或模糊文字可能需手动字体/区域修正。
采样间隔内的极短字幕可能遗漏；base 语音模型对嘈杂、口音或专业词可能识别不准。
视频模式先生成时间轴再编码，播放时不依赖翻译网络速度。
受保护视频和独占全屏游戏可能无法截图，可尝试无边框窗口模式。

数据与费用
OCR、视频解析、修补、语音识别、编码均在本地完成。
不上传截图、视频或音频；仅识别文本发送至配置的翻译 API，按服务商规则计费。
密钥由当前 Windows 账户加密保存：%LOCALAPPDATA%\ScreenLens\settings.json。
屏幕翻译只在内存缓存；视频模式按你的选择保存成片、字幕和项目。
软件不附带 API Key；本地语音识别不调用付费语音 API。
401 密钥无效；402 余额不足；404 模型/地址错误；429 服务限流。

验证
63 项自动测试通过，并完成源码与打包版的原生覆盖和三种视频路径检查。
测试的 OCR、语音识别、编码、音轨、时间轴真实运行；译文来自本机模拟接口。
尚未用用户实际视频验收，测试不能证明真实云端翻译质量或网络延迟。
