# Qt for Python open-source licensing

The installed PySide6-Essentials 6.12.0 and Shiboken6 6.12.0 distributions
declare `LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only` in their package
metadata. The ScreenLens project uses their open-source GPLv3 option.

Some wheels include a file named `LicenseRef-Qt-Commercial.txt`. It is
retained as supplied, but does not replace the open-source license options
declared by the distribution. `GPL-3.0.txt` contains the GPLv3 text.

Upstream information and source repositories:

- https://doc.qt.io/qtforpython-6/licenses.html
- https://pypi.org/project/PySide6-Essentials/
- https://code.qt.io/pyside/pyside-setup.git/
- https://code.qt.io/qt/qtbase.git/
- https://code.qt.io/qt/qtdeclarative.git/

Qt libraries and bindings retain their respective upstream copyrights.
